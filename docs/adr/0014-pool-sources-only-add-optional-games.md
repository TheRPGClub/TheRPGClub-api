# Pool sources only ever add Optional Games; a person sets every Core Game

A Pool can draw games from live sources (a Franchise, a Series, or a linked Game List), and those sources keep changing: Regulars edit Franchises, IGDB adds games, list owners add to their lists. We decided that a game arriving from a source always joins the Pool as an Optional Game, and only a person (the Host, or a Moderator or above) makes it a Core Game. We rejected resolving the required set live from a source, because then a Franchise edit or an IGDB refresh could silently make every unfinished Run harder, with nobody having chosen to. We also rejected freezing the Pool when the first Run starts, because a new mainline entry (a Final Fantasy XVII) has to be addable to a running Challenge.

## Consequences

- Adding a Core Game is always a deliberate act, so it is the one Pool change that notifies members in a Run. A new Optional Game arrives silently.
- A game the Host removes from a Challenge is remembered as excluded, so its source cannot add it back.
- Runs that already Finished stay Finished when a Core Game is added later.
- Add-ons are never added by a source. They join a Pool only when someone picks them by hand.
